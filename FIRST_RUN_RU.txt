Albion Trade Desk — локальный AOD

Это исходный дистрибутив для Windows 10/11 x64. Windows exe в текущем Linux-окружении не собран.

1. Распакуйте ZIP полностью. Нужен Python 3.12 или новее.
2. Дважды нажмите start.cmd. Дальше работайте в открывшемся браузере.
3. Выберите сервер игры (по умолчанию Asia / East), откройте «Мои наблюдения» и нажмите «Запустить сборщик» после ручного включения. Разрешите запрос Windows и выберите установленный официальный AOD 0.1.61 (не installer). Путь запоминается. Нужен Npcap.
4. Вручную откройте рынок в Albion. В панели появятся счётчики. В «Цены предметов» выберите свой город и «Только мои наблюдения». Самим ордерам посвящена кнопка «Мои ордера · Excel».

Остановить AOD: «Остановить сборщик». Закрыть Trade Desk: «Данные и настройки» → «Закрыть Trade Desk».

База: %LOCALAPPDATA%\AlbionTradeDesk\trade-desk.sqlite3. Обновление программы её не удаляет.

Публичный API выключен по умолчанию и не нужен для сбора. Для имён/рецептов можно отдельно разрешить загрузку каталога в «Источниках»; без него видны игровые ID.

Полная проверка настоящего Windows AOD с игрой и Firewall ещё не выполнена; разрешение SBI не подтверждено. Автозапуска нет. Регион игры не содержится в native HTTP AOD: убедитесь в совпадении выбранного региона и игры. Не переключайте сервер во время активной сессии.

Подробности и проверки: README.md, docs/PRIVATE_SCANNER.md, docs/AOD_IMPLEMENTATION_VALIDATION.md.
