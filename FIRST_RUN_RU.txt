Albion Trade Desk — Windows x64

1. Распакуйте AlbionTradeDesk-Windows-x64.zip полностью и дважды откройте AlbionTradeDesk.exe. Python не нужен. Не запускайте программу из открытого ZIP.
2. Выберите сервер игры (по умолчанию Asia / East). Откройте «Мои наблюдения», отметьте ручное включение и нажмите «Запустить сборщик».
3. Разрешите запрос Windows. Программа найдёт установленный официальный AOD 0.1.61 либо попросит выбрать его exe (не installer). Файл проверяется по SHA-256; путь запоминается.
4. Если установщик включил обычный автозапуск AOD, отдельный диалог предложит временно приостановить его. После подтверждённой остановки он восстановится. Другие запущенные копии AOD нужно закрыть самостоятельно.
5. Вручную откройте рынок в Albion. В панели появятся счётчики. В «Цены предметов» выберите свой город и «Только мои наблюдения». Для самих ордеров есть «Мои ордера · Excel».

Остановить сборщик: «Остановить сборщик». Закрыть программу: «Данные и настройки» → «Закрыть Trade Desk». Закрытие вкладки браузера само по себе не завершает программу.

Нужны уже установленные AOD 0.1.61 и Npcap. Они автоматически не скачиваются и не устанавливаются. Если Npcap отсутствует, программа покажет инструкцию. Не используйте обычный AOD одновременно с приватным сборщиком.

База: %LOCALAPPDATA%\AlbionTradeDesk\trade-desk.sqlite3. Обновление программы её не удаляет. Путь и размер видны в панели.

Публичные загрузки выключены по умолчанию. Для русских названий/рецептов можно отдельно включить каталог в «Источниках»; без каталога предметы сохраняются по игровым ID. SQLite вручную настраивать не нужно.

На Windows CI прошли 83 теста, проверка готового exe и проверка политики Firewall/WFP на отдельном тестовом процессе. Настоящая игра/AOD capture/Npcap не запускались, полной сертификации приватности нет. Автозапуск сборщика выключен. Native HTTP AOD не передаёт server ID: сверяйте регион игры с выбранным в сессии и не переключайте его до остановки.

Если используется исходный ZIP вместо exe: установите Python 3.12+ и откройте start.cmd.

Подробности: docs/WINDOWS_BUILD_RESULT.md и docs/PRIVATE_SCANNER.md.
