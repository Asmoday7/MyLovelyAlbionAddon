# Модель данных и расчётов

## Phase 1: наблюдения

Цена выбирается по наиболее свежему observed_at **отдельно** для sell_min и
buy_max, с сохранением источника, received_at и limitation. Порог устаревания
задаёт пользователь. Устаревшее значение можно увидеть, но оно не становится
текущим из-за обновления кэша. Spread=sell_min−buy_max, spread%=spread/buy_max×100.
Оба значения должны существовать. Отрицательный spread не исправляется.

Текущая реализация 1H/24H/7D: последние 1/24/168 **завершённых UTC часов**,
верхняя граница floor(now/3600)*3600, интервал полуоткрытый [start,end).
Это не точное скользящее окно до текущей секунды. Интервалы history временно
трактуются как start-labelled: этот контракт требует живой проверки Asia.

Для каждой метрики показываются known_quantity и coverage. Только при 100%
покрытии volume содержит число; без покрытия это null. Частичная сумма — нижняя
граница, не оценка полного спроса. Пропуски не заполняются нулями. Один источник
и масштаб на один интервал; перезагрузка того же интервала обновляет запись,
а не складывает объём. 6h/24h не распределяются искусственно по часам.

VWAP=sum(avg_price×quantity)/sum(quantity) по доступным закрытым почасовым
интервалам 7D. Это историческая величина с собственной полнотой, не цена ордера.
Volatility — взвешенное стандартное отклонение цен интервалов / VWAP, не
волатильность каждой сделки. Daily average=volume_7d/7 только при полном 7D.
Turnover_24h=sum(quantity×average) только при полном покрытии.
Аномалия: текущая цена вне [VWAP/3, VWAP×3] (эвристика, минимум 3 интервала),
без подмены фактической котировки исторической средней.

## Следующие этапы (ещё не реализованы)

Производство: material_cost=sum(price×count×(1−RRR)) только для возвращаемых
ресурсов; артефакты/maxreturnamount=0 без возврата. Учёт output, серебра за
операцию, станции, focus-efficiency, Premium и способа продажи. Не закреплять
старые налоги или городские бонусы без актуальной проверки.

BM: instant revenue берётся только из buy_max, качество не смешивается.
Нельзя обещать продажу партии по цене заявки на одну единицу. Оценочные
транспортные потери отдельно от детерминированных расходов.

Бизнес-скоринг/оптимизатор: раздельно факты, оценки и сценарии. Доля рынка
5/10/20% — ввод пользователя. Историческая частота маржи не вероятность
будущей прибыли. Пока эта модель не реализована, UI не выдаёт рекомендации.
