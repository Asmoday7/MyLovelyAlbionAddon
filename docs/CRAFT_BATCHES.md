# Крафт и закупка · 0.2.0

## Рабочий процесс

1. Разверните «Выбрать предмет», выберите рецепт, тир, чары и количество.
   Выбор после нажатия сворачивается; длинной левой колонки больше нет.
2. Нажмите «Добавить рецепт в партию». Добавляйте разные вещи: одинаковые
   материалы объединяются по игровому ID, серверу, рынку и качеству.
   «Сравнить кристальное оружие» добавляет доступные в каталоге рецепты
   выбранного тира и зачарования; существующие строки не дублируются.
3. Укажите проценты возврата из окна станка с Focus и без него. Они не
   выводятся из города автоматически. В строке рецепта можно задать отдельные
   проценты, фактический Focus на операцию, станцию и свою цену продажи.
4. Обновите общие цены и историю всей партии одной кнопкой либо используйте
   собственные сканы. Загрузка общих данных требует включения публичных загрузок
   в «Источники данных» и после успеха выбирает для партии «Все источники».
   Собственные наблюдения при этом не отправляются.
5. Сравните прибыль, прибыль на штуку, ROI, серебро на Focus и известные продажи.
   Измените количества и удалите ненужные позиции.
6. Закупайте по общей очереди или нажмите «Скопировать код закупки для Albion».
   Сохраните партию, чтобы её состав, ручные цены и отметки закупки не потерялись.

## Игровые коды комплектов

Пользователь предоставил реальный экспорт игры:

```json
{"version":1,"name":"Т4 Рекликты","icon":6,"inventory":[{"item":"T4_RELIC","quality":1,"stack":48}]}
```

Экспорт повторяет эту схему версии 1. В inventory передаются игровые ID,
качество 1 и целое количество. По умолчанию берётся «Докупить»; переключатель
позволяет включить уже купленное. Цены, личные данные и адрес сборщика не
попадают в код. Язык названий списка не влияет на игровые ID в коде.

Порядок в игре: «Комплекты» → «Вставить текст» / Paste Text → проверить состав
и сохранить → выбрать комплект в быстрой покупке рынка. После вставки
сверяйте количество и сообщения о пропущенных строках.

Программа по умолчанию делит экспорт на коды по 10 строк и стеки до 999 единиц.
Это настраиваемое разбиение программы, а не подтверждение лимитов текущего
игрового клиента. Ограничение конкретного предмета из каталога имеет приоритет;
для ингредиентов-снаряжения используется размер стека 1. Если игра отсекает
строки, уменьшите число строк на код. Названия частей имеют номер, а кнопка
«Следующий код» копирует очередную часть. При изменении количества или состава
старый код скрывается. Требуется повторная генерация.

Тесты подтверждают JSON-схему по предоставленному примеру и сохранение точных
количеств при разбиении. Импорт сгенерированного смешанного набора в живой Albion
и фактические лимиты быстрой покупки здесь не проверены.

## Как считается результат

Полный расход рецепта × число операций определяет стартовую закупку.
Выход нескольких предметов округляет операции вверх и показывает излишек.
Возврат не уменьшает стартовый список. Невозвратные компоненты не дают возврата.

Безвозвратный результат = выручка после налога и размещения − полный расход
материалов − размещение заявок покупки − серебро рецепта − станция − перевозка.
Ожидаемый результат с возвратом добавляет стоимость возвращаемых ресурсов
по выбранной цене материалов. Возврат остаётся запасом, а не выручкой серебром.
Перевозка вычитается из итога партии, но не распределяется по строкам сравнения.

Доступны немедленная покупка/продажа и заявки. Для материалов используются
sell/buy цены соответственно; для готовых вещей — выбранное качество.
Black Market использует заявку покупателя, без размещения sell-заявки.
Налог по умолчанию 8%, размещение 2.5%; параметры следует сверять с игрой
(при Premium обычно налог 4%). Расходы станции и перевозки изначально нулевые
и показаны как отдельные настройки. Отсутствующие цены и проценты возврата
не подменяются нулём. Ручная цена может явно заменить рыночную.

«Уже есть / куплено» уменьшает только остаток закупки, а не стоимость всех
использованных материалов. Это учёт количеств, не журнал фактических сделок:
в основе оценки текущая рыночная либо введённая вручную цена.
Продажа всего выпуска в выбранном качестве — сценарий, не предсказание
распределения качества при крафте.

Focus не меняет налог продажи. Для серебра на Focus требуется фактический
расход Focus из окна станка; базовая цифра рецепта показана лишь как подсказка.

## Ликвидность

Используется история за 7 дней для того же сервера, города, предмета, рамки
и выбранного набора источников. Показываются известные продажи, полнота
часов либо число исходных игровых точек. Пропуски не считаются нулём.
Ориентир количества = выбранная доля известных продаж (по умолчанию 10%).
Неполная история делает его предварительным; это не доказательство полного
спроса. Срок по наблюдаемому темпу также оценочный и не гарантирует продажу.
Неизвестная история остаётся неизвестной, а не нулевой ликвидностью.

## Хранение и проверка

Именованные партии сохраняются в новой таблице craft_batches. Старые
однопредметные craft_packs сохраняются отдельно. Рабочий черновик и отметки
закупки хранятся также в localStorage. Рыночные таблицы не очищаются.

До ограничения среды полный Linux-прогон: 103 теста, 100 успешно, 3 Windows-only
пропущены. Первоначальный Chromium-сценарий смешанной партии прошёл: объединение
материалов, Focus/без Focus, неполная ликвидность, копирование количества,
отметки закупки, перезагрузка, мобильная ширина и ошибка выключенных загрузок.
После добавления игрового экспорта прошли 28 автономных тестов крафта, партии
и кодов, проверки синтаксиса JS/Python и наличия DOM ID.

Повторные Chromium-сценарии, включая новый экспорт и успешную общую загрузку,
не запустились: автоматическая проверка разрешений сообщила об исчерпанном
лимите использования. Это сбой проверки, не заключение о небезопасности кода.
Новый Windows exe требует отдельной CI-сборки; старый exe не обновляется сам.

Проверки для последующего запуска:

```sh
python -m unittest discover -s tests -v
NODE_PATH=/opt/codex/cua_node/lib/node_modules python scripts/check_craft_batch_ui.py
NODE_PATH=/opt/codex/cua_node/lib/node_modules python scripts/check_materials_ui.py
NODE_PATH=/opt/codex/cua_node/lib/node_modules python scripts/check_history_ui.py
```
