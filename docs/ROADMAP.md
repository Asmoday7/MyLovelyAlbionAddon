# Этапы и критерии завершения

Полное ТЗ получено в последующем сообщении пользователя; исходный приложенный
файл `MASTER_SPECIFICATION.md` обрывается в §5. Требования полного сообщения
включают §0–20, Phase 0→6, обязательный Excel, прозрачность данных и тёмную тему
с пастельными оранжевыми/розовыми акцентами. Это источник текущих приоритетов.

1. **Phase 0 — Research & Validation.** Аудиты конкурентов/источников,
   архитектура, экономика и roadmap. Исходники изучены. Открыто: живой Asia API,
   закрытые сетевой политикой сайты, подтверждение временных границ history.
2. **Phase 1 — Working Core (текущий этап).** Реальный каталог, SQLite,
   поиск RU/EN/ID, все восемь рынков, раздельные серверы/качества, импорт цен и
   почасовой истории, coverage/свежесть, таблица и фильтры, CSV/XLSX, Power Query,
   резервная копия. Для полного acceptance нужны живые prices/history Asia,
   проверка BM и проверка запуска на Windows; отсутствие доступа не маскируется.
3. **Phase 2 — Local Market Scanning.** Развить эксперимент ingress в
   полноценную панель сканов, проверить в Windows с официальным Data Client и
   ручным просмотром рынка, timestamps, region routing, дедупликацию и неполноту.
4. **Phase 3 — Crafting & Black Market.** Себестоимость, focus, batch/output,
   артефакты, станции, комиссии, Caerleon→BM и craft→BM, карточка с расшифровкой.
5. **Phase 4 — Runes, Artifacts & Trading.** Общий движок преобразований,
   последовательное enchanting из реальных upgrade requirements, артефакты,
   flipping, маршруты с весом/слотами и устойчивость по истории.
6. **Phase 5 — Business Intelligence.** Объяснимый многокритериальный
   скоринг, оптимизация бюджета/focus/ликвидности с лимитом доли на товар,
   партия/оборот/прибыль в сутки, сценарии, бэктестинг, ledger и фактический P&L.
7. **Phase 6 — Advanced.** Refining city bonuses, journals, farming/islands,
   food/potions, salvaging, gold, Excel import с явным mapping и без перезаписи
   формул, Windows installer. Данные должны быть проверены по актуальным механикам.

Не делаем одновременно все разделы меню заглушками. По мере реализации
появляются работающие экраны. Каждый этап — отдельные логические коммиты,
тесты на экономические ошибки и отчёт о фактических ограничениях.


### Дополнение: Private Market Scanner

Добавлены отдельная выключенная по умолчанию сессия, market-only receiver,
источники v2, все native масштабы истории, Windows guarded launcher и
read-only NATS. Протокол проверен сетевым экспериментом с upstream uploader;
приём в UI и SQLite проверен локально. Этап **не завершён** до live Windows,
сетевой проверки и проверки правил SBI: см. PRIVATE_SCANNER.md. Конфликт
8765 с AnkiConnect исправлен отдельно; все новые адреса используют фактический
свободный порт.
