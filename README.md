# Albion Trade Desk — как установить и пользоваться

Это инструкция для **Windows 10/11**. Программировать и вводить команды не нужно.

Trade Desk — наша программа с таблицами цен Albion. Она открывается в обычном
браузере, но работает на вашем компьютере. Данные сохраняются у вас.

**Сейчас это первая версия:** можно загрузить список предметов, запросить цены,
посмотреть доступную историю и сохранить таблицу в Excel. Поиск выгодного крафта,
оптимизатор денег и учёт портфеля ещё не готовы. Запуск именно на Windows и
подключение настоящей игры пока не проверены; если появится ошибка, её нужно
разобрать, а не считать установку успешно завершённой.

## Что делать сейчас: четыре шага

### 1. Скачайте нашу программу

Нажмите **[Скачать Albion Trade Desk — ZIP](https://github.com/Asmoday7/MyLovelyAlbionAddon/archive/refs/heads/main.zip)**.

Найдите скачанный архив в папке «Загрузки». Нажмите на него правой кнопкой мыши
→ **«Извлечь всё…»** → **«Извлечь»**.

Откройте распакованную папку. Внутри должен быть файл **`start.cmd`**.
Если Windows скрывает окончания файлов, он может называться просто **`start`**.
Запускать его нужно **из распакованной папки**, а не из открытого ZIP-архива.
Можно перенести всю распакованную папку в «Документы».

### 2. Один раз установите Python

Python — бесплатная программа, которая нужна для запуска Trade Desk.
Пользоваться самим Python вам не придётся.

Откройте **[официальную страницу Python для Windows](https://www.python.org/downloads/windows/)**.
Выберите обычный установщик **Windows installer (64-bit)** для стабильной версии
**Python 3.12 или новее**. Не выбирайте «embeddable package» и предварительные
версии с пометками alpha/beta/rc.

Запустите скачанный установщик. Если на первом экране есть галочка
**«Add python.exe to PATH»**, поставьте её. Затем нажмите **«Install Now»**
и дождитесь окончания установки.

Если Python 3.12 или новее уже установлен, этот шаг можно пропустить.

### 3. Откройте Trade Desk

В распакованной папке дважды нажмите **`start.cmd`**.

Откроются два окна:

* **Тёмное окно с текстом** — оставьте его открытым, это работающая программа.
* **Вкладка браузера Albion Trade Desk** — здесь вы будете смотреть таблицы.

Если браузер сам не открылся, скопируйте в его адресную строку:

```text
http://127.0.0.1:8765
```

Этот адрес открывает программу на вашем компьютере. Его нужно открывать там же,
где запущен `start.cmd`; с телефона или другого компьютера он её не откроет.

### 4. Загрузите предметы и первые цены

При первом запуске таблица может быть пустой — это нормально. Скачанный ZIP
содержит программу, а список предметов она загружает отдельно.

1. Слева откройте **«Данные и настройки»**.
2. Нажмите **«Синхронизировать каталог»** и дождитесь сообщения
   **«Обновление завершено»**. Это загрузит названия и рецепты предметов.
3. Вернитесь в **Market Intelligence** — так называется основная таблица цен.
4. Вверху справа выберите **Asia / East**, если играете на азиатском сервере.
5. В строке поиска введите **«Сумка»**. Выберите в фильтрах нужный город
   и качество предмета.
6. Поставьте галочку **слева от одного предмета**, затем нажмите
   **«Обновить выбранные»**.
7. Дождитесь окончания обновления. Если у источника есть наблюдения для этого
   предмета, города и качества, они появятся в таблице.

**Для этой первой проверки запускать Albion Online и Albion Data Client не нужно.**
Нужен доступ в Интернет.

## Что означают столбцы

| Надпись | Простыми словами |
|---|---|
| Sell min | Самая низкая известная цена, по которой кто-то выставил предмет на продажу |
| Buy max | Самая высокая известная цена заявки на покупку: предложение покупателя |
| 1H / 24H / 7D | Известный объём продаж за последние завершённые час / 24 часа / 7 суток |
| Свежесть | Сколько времени прошло с наблюдения цены |
| `—` | Данных нет; это **не нулевая цена** и не доказательство отсутствия продаж |
| `≥` перед объёмом | История неполная; показана только известная часть продаж |

Источник цен обновляется силами игроков, поэтому некоторые предметы и города
могут не иметь свежих данных. Доступная цена не гарантирует, что по ней удастся
купить или продать целую партию. Интерпретация временных границ истории ещё
ожидает живой проверки; пока не используйте объёмы как подтверждённую основу
крупной сделки.

**Caerleon и Black Market — два разных рынка.** Для Black Market показывается
цена заявки на покупку, а не обычная цена выставления товара.

## У меня уже есть старый Albion Data Client. Что с ним делать?

**Пока оставьте его как есть. Для первого запуска Trade Desk он не требуется.**

Это две отдельные программы:

* **Trade Desk** показывает и анализирует полученные данные.
* **Albion Data Client** собирает наблюдения, когда вы вручную смотрите рынок
  в игре, и отправляет их в общую базу Albion Data Project.

Обычный запуск старого клиента **ещё не подключает его напрямую к Trade Desk**.
Для прямой передачи нужна дополнительная настройка ниже. Она пока
экспериментальная: формат проверен по исходникам и тестами, но не реальным
запуском игры на Windows.

### Если хотите обновить официальный клиент

1. Закройте старый Data Client, в том числе его значок возле часов Windows,
   если он там есть. Две копии одновременно запускать не нужно.
2. Откройте **[официальную страницу последнего выпуска](https://github.com/ao-data/albiondata-client/releases/latest)**.
3. Внизу страницы раскройте **Assets** — это список файлов для скачивания.
4. Скачайте **`albiondata-client-amd64-installer.exe`** и запустите установку.
   Файлы `Source code`, `.gz` и вариант `mac.zip` для этого не нужны.
5. После установки запустите клиент. Если прежняя версия уже работает
   и собирает данные, переустанавливать всё ради первого запуска Trade Desk
   не требуется.

Название Windows-установщика проверено на официальной странице выпуска.
Ссылка выше всегда ведёт к выпуску, отмеченному авторами как последний.

**Про Npcap:** это отдельный компонент, который может понадобиться Data Client
для получения рыночных данных из игры. Если клиент сообщает, что его нет,
используйте **[официальную загрузку Npcap](https://npcap.com/#download)**.
При установке выберите **«Install Npcap in WinPcap API-compatible Mode»**,
если этот пункт предлагается. Если старый клиент уже успешно собирает данные,
начинать с переустановки драйвера не нужно.

   ```text
   -i "https+pow://albion-online-data.com,http://127.0.0.1:8765/ingest/east"
   ```

5. Нажмите **«Применить»**, затем запустите Data Client этим ярлыком.
   Настройка сохраняет обычную отправку в общую базу и добавляет отправку
   в Trade Desk.
6. Запустите игру на **Asia** и **вручную откройте рынок**. Просмотрите
   интересующие предметы.
7. В Trade Desk откройте **«Источники и сканер»**. Если пакеты поступают,
   там появятся записи о последних локальных обновлениях.
8. Вернувшись в таблицу, повторите поиск или выбор города, чтобы перечитать
   полученные данные. Они пока не появляются в открытой таблице автоматически.

Обе программы и игра должны работать **на одном Windows-компьютере**.
Эта настройка рассчитана на Asia; для другого игрового сервера адрес нужно
изменить, иначе наблюдения попадут не в тот раздел базы.

Если в свойствах нет поля «Объект», вероятно, открыты свойства самой программы,
а не ярлыка. Пришлите скриншот окна — подскажем следующий шаг.

Если обновления не появились, это ещё не означает, что вы что-то сделали
неправильно: интеграция пока экспериментальная. Полного сканирования всего
рынка и автоматического перелистывания окон игры здесь нет.

## Как пользоваться потом

* **Открыть приложение:** дважды нажать `start.cmd` в той же папке.
* **Обновить цены:** выбрать сервер, город и качество, отметить предметы
  и нажать «Обновить выбранные». Каталог каждый раз скачивать не надо.
* **Посмотреть другие города:** нажать на название предмета в таблице.
  В карточке будут только те рыночные данные, которые уже получены.
* **Сохранить в Excel:** нажать **«↓ Excel»** над таблицей. Скачается новый
  файл; существующие Excel-книги программа не меняет.
* **Закрыть приложение:** в тёмном окне с текстом нажать **Ctrl+C**.
  Если закрыть только вкладку браузера, сама программа продолжит работать.

Данные и избранное находятся в папке **`data`** рядом с `start.cmd`.
Не удаляйте её, если хотите сохранить свою базу. При скачивании новой версии
программы старую папку с данными сначала сохраните; она не включена в ZIP с GitHub.

## Если что-то не получается

| Что случилось | Что сделать |
|---|---|
| `start.cmd` не запускает приложение или пишет, что Python не найден | Завершите установку Python из шага 2. Если установлен старый Python, нужна версия 3.12 или новее. Запустите `start.cmd` ещё раз |
| Браузер не открылся | Пока тёмное окно работает, вручную откройте адрес из шага 3 |
| Адрес в браузере не открывается | Проверьте, что тёмное окно не закрылось и в нём нет ошибки. Сам адрес без запущенного `start.cmd` не работает |
| Таблица совсем пустая | Загрузите каталог в «Данные и настройки». Если он уже загружен, очистите поиск и отключите «Избранное» / «Только с ценами» |
| Предметы видны, но вместо цен прочерки | Выберите один предмет и нажмите «Обновить выбранные». Проверьте выбранные город, сервер и качество. У источника также может не быть нужных наблюдений |
| Обновление показывает ошибку | Скопируйте сообщение из приложения или пришлите скриншот. Переустановка Data Client не исправляет все ошибки загрузки цен |
| При запуске написано, что адрес уже используется | Возможно, Trade Desk уже работает в другом тёмном окне. Сначала попробуйте открыть его в браузере |

Если застряли, достаточно прислать **скриншот последнего окна и номер шага**.
По ним можно будет понять, что именно мешает запуску.
