# Albion Trade Desk — как установить и пользоваться

**Готовая Windows x64 сборка 0.3.1 получена и проверена на Windows CI.**

[Скачать AlbionTradeDesk-Windows-x64.zip · 0.3.1](https://github.com/Asmoday7/MyLovelyAlbionAddon/actions/runs/41871657888/artifacts/13344857008).
Для скачивания артефакта нужен вход в GitHub с доступом к репозиторию.
Распакуйте архив и откройте **AlbionTradeDesk.exe**. Python и исходники рядом
не требуются; AOD 0.1.61 и Npcap устанавливаются отдельно.

Старая прямая ссылка на ветку `builds/aod-e91c562aa93c-41271027327-1`
ведёт к архивной версии 0.1.0: в ней нет исправления HTTP 400 при смене
кодов одного рынка (`1002`, `1000`, `1000-HellDen`). Перезапуск старого exe
его не обновляет. Закройте старую программу и сборщик перед запуском нового exe;
не удаляйте базу в `%LOCALAPPDATA%\AlbionTradeDesk`. При обновлении существующие
рыночные коды исправляются автоматически с резервной копией.

В 0.3.1 подбор проверяет все подходящие рецепты и показывает все результаты
сразу, без лимита 300 и без страниц. В «Мои наблюдения» выводится конкретная
причина последнего HTTP 400 с номером записи и полем.

Дважды откройте exe → «Мои наблюдения» → выберите сервер → «Запустить сборщик». Нужны установленные AOD 0.1.61 и Npcap. Полный первый запуск — в FIRST_RUN_RU.txt.

На Windows для 0.3.1 прошли **126 тестов без пропусков**, проверка упакованного exe (HTTP/SQLite/Excel/остановка) и реального Firewall/WFP на synthetic probe. [Доказательства](docs/WINDOWS_BUILD_RESULT.md). Настоящая игра, захват через Npcap и полная приватность AOD на пользовательском ПК пока не проверены.

Ниже сохранена инструкция для запуска из исходников, если exe не используется.


Это инструкция для **Windows 10/11**. Программировать и вводить команды не нужно.

Trade Desk — наша программа с таблицами цен Albion. Она открывается в обычном
браузере, но работает на вашем компьютере. Данные сохраняются у вас.

**Сейчас можно:** загрузить список предметов, запросить цены, собрать и сохранить
набор ресурсов для крафта, посмотреть доступную историю и сохранить таблицу в Excel. Поиск выгодного крафта,
оптимизатор денег и учёт портфеля ещё не готовы. Сборка и синтетическая проверка на Windows выполнены;
подключение настоящей игры пока не проверено; если появится ошибка, её нужно
разобрать, а не считать установку успешно завершённой.

## Что делать сейчас: четыре шага

### 1. Скачайте нашу программу

Нажмите **[Скачать Albion Trade Desk — ZIP](https://github.com/Asmoday7/MyLovelyAlbionAddon/archive/refs/heads/main.zip)**.

Найдите скачанный архив в папке «Загрузки». Нажмите на него правой кнопкой мыши
→ **«Извлечь всё…»** → **«Извлечь»**.

Откройте распакованную папку. Внутри должен быть файл **`start.cmd`**.
Если Windows скрывает окончания файлов, он может называться просто **`start`**.
Запускать его нужно **из распакованной папки**, а не из открытого ZIP-архива.
Можно перенести всю распакованную папку в «Документы».

### 2. Один раз установите Python

Python — бесплатная программа, которая нужна для запуска Trade Desk.
Пользоваться самим Python вам не придётся.

Откройте **[официальную страницу Python для Windows](https://www.python.org/downloads/windows/)**.
Выберите обычный установщик **Windows installer (64-bit)** для стабильной версии
**Python 3.12 или новее**. Не выбирайте «embeddable package» и предварительные
версии с пометками alpha/beta/rc.

Запустите скачанный установщик. Если на первом экране есть галочка
**«Add python.exe to PATH»**, поставьте её. Затем нажмите **«Install Now»**
и дождитесь окончания установки.

Если Python 3.12 или новее уже установлен, этот шаг можно пропустить.

### 3. Откройте Trade Desk

В распакованной папке дважды нажмите **`start.cmd`**.

Откроются два окна:

* **Тёмное окно с текстом** — оставьте его открытым, это работающая программа.
* **Вкладка браузера Albion Trade Desk** — здесь вы будете смотреть таблицы.

Если браузер сам не открылся, скопируйте в его адресную строку **адрес из тёмного
окна после надписи `Адрес приложения:`**. Порт программа выбирает сама: если
`8765` занят, например AnkiConnect, она попробует следующий свободный.
Открывать всегда один и тот же адрес `127.0.0.1:8765` не нужно — это может
оказаться другая программа.

Этот адрес открывает программу на вашем компьютере. Его нужно открывать там же,
где запущен `start.cmd`; с телефона или другого компьютера он её не откроет.

### 4. Запустите локальный сбор

1. Вверху выберите сервер игры (по умолчанию Asia / East).
2. Откройте **«Мои наблюдения»**, прочитайте ограничение проверки и отметьте ручное включение.
3. Нажмите **«Запустить сборщик»**. Разрешите запрос Windows; при первом запуске выберите установленный **AOD 0.1.61 x64**, не его installer. Выбранный файл проверяется по закреплённому SHA-256 и запоминается.
4. Вручную откройте рынок в Albion. Ордера появятся в SQLite; счётчики, время последнего пакета и размер базы — на этой же панели.
5. В «Цены предметов» выберите тот же город и «Только мои наблюдения». Для выгрузки самих ордеров нажмите **«Мои ордера · Excel»** в панели сборщика.
6. Кнопка **«Остановить сборщик»** завершает только запущенный нами AOD. Не переключайте сервер игры во время сессии: остановите сбор, выберите новый регион и запустите заново.

Каталог и публичный API для сбора не нужны. Без каталога предметы показываются по игровым ID. Для русских названий/рецептов и чужих цен откройте **«Источники данных» → «Разрешить дополнительные публичные загрузки»**. Эта возможность по умолчанию выключена и не отправляет ваши наблюдения.

Нужны уже установленный оригинальный AOD 0.1.61 и Npcap. Trade Desk не скачивает и не исполняет неизвестные бинарники автоматически. Если проверка файла, драйвера или брандмауэра не прошла, AOD не запускается; причина отображается в панели. Другая запущенная копия AOD блокирует запуск, а не завершается принудительно.

Полная проверка с реальной игрой и Windows Firewall ещё не выполнена; автоматического включения или восстановления сессии после перезапуска нет. Сервер игры не входит в штатный HTTP AOD: показывается выбранный сервер сессии, а не выдуманный результат автоопределения. Подробности — [PRIVATE_SCANNER.md](docs/PRIVATE_SCANNER.md).

### Дополнительно: загрузите предметы и общие цены

Сначала явно разрешите публичные загрузки в разделе «Источники данных».



После запуска работайте **в браузере**. Тёмное окно можно свернуть.

1. На странице **«Цены предметов»** нажмите большую кнопку
   **«Загрузить список предметов»**. Если список ещё пуст, выбирать пока нечего.
   При первом запуске загрузка может занять несколько минут.
2. Дождитесь сообщения **«Список готов»**. Внизу появятся поиск и таблица.
   Список содержит названия и рецепты; сами цены ещё нужно запросить.
3. Для первого раза нажмите **«Найти кристалл разлома IV»**. Появится предмет
   **«Кристалл разлома (знаток)»** — тот же **Adept’s Rift Crystal** в игре.
   Можно также нажать пример с сумкой или ввести название вручную.
4. Выберите **тот же сервер, город и качество, что в игре**. Например:
   **Азия / Asia / East → Lymhurst → Обычное**.
5. В строке предмета справа нажмите **«Узнать цену»**. **Галочка для одного
   предмета не нужна.** Дождитесь результата загрузки.
6. В столбце **«Продают от»** будет минимальная известная цена продавца,
   в **«Покупают до»** — максимальная известная заявка покупателя.

Не нужно искать предметы в левом меню. **Слева — разделы программы, сами
предметы находятся в таблице в центре.** Галочки в первом столбце нужны только
для загрузки нескольких предметов сразу: отметьте их и нажмите
**«Загрузить цены выбранных» под таблицей**.

Если строк нет, нажмите **«Сбросить фильтры»**. Если строки есть, но написано
«Нет цены», источник мог не знать цену для этого города и качества. Если
появилось сообщение об ошибке, раскройте **«Текст ошибки для диагностики»**
и пришлите его — это отдельная ситуация, не отсутствие спроса.

**Для первых общих цен Albion Online и Data Client запускать не нужно.**
Нужен Интернет. Открытие рынка в игре само по себе не подключает игру к Trade Desk.

### Хочу скрафтить предмет — что смотреть на рынке?

1. Слева нажмите **«Крафт и наборы»**. Экран сам сравнит рецепты по текущей базе.
   Выберите города закупки и продажи, тир, чары и категорию. Например,
   **«Кристальное оружие»** для сравнения Forgebark и других кристальных вещей.
2. Нажмите **«Обновить цены и продажи»**. Если общие загрузки выключены,
   кнопка прямо предложит их включить. Материалы, готовые предметы и история
   всех рамок загружаются здесь же. Игра и Data Client для этой кнопки не нужны.
3. Сравните **материалы на штуку, прибыль после налогов и продажи за 7 дней**.
   Все пять рамок видны сразу. Общая оценка использует диапазон I–IV;
   шедевры показаны отдельно. Переключите сортировку от большей прибыли к
   меньшей или наоборот, покажите убыточные варианты либо вещи без данных.
4. У подходящих вещей задайте количество и нажмите **«В закупку»**.
   Одинаковые материалы объединяются. По известным продажам показан ориентир
   размера партии, а её прибыль пересчитывается автоматически.
5. Нажмите **«Скопировать код закупки для Albion»**, вставьте код через
   **«Комплекты» → «Вставить текст» / Paste Text** в игре и проверьте состав.
   Также можно последовательно копировать названия и количества материалов.
   Сохранение партии запоминает состав и отметки закупки на этом компьютере.

По умолчанию оценивается покупка материалов сразу и выставление готовых вещей
без Premium: налог **8% + размещение 2,5%**, без Focus. Если хотите учитывать
возврат, один раз укажите его процент в свёрнутом блоке над подбором.
Плата станции, перевозка, Focus и ручные цены доступны в дополнительных
настройках партии. Подробности расчёта и ограничения: [CRAFT_BATCHES.md](docs/CRAFT_BATCHES.md).

Для ручного выбора раскройте **«Добавить конкретный рецепт вручную»**.
Здесь остаются поиск, например **«forge bark»**, и точные параметры рецепта.
Собственные сканы продолжают обновлять цены и подбор автоматически.
Пропуски истории остаются неизвестными. Показанная прибыль — оценка:
качество крафта случайно, а объём рынка по лучшей цене может быть ограничен.

### Что должно быть в тёмном окне

После `start.cmd` вы увидите примерно такой текст:

```text
Albion Trade Desk запущен.
Адрес приложения: http://127.0.0.1:8766
Окно можно свернуть. Все действия выполняйте в браузере.
Первый запуск: нажмите «Загрузить список предметов» в приложении.
Для остановки нажмите Ctrl+C.
```

**Число после двоеточия в адресе может быть другим.** Используйте адрес из
вашего окна. Ничего вводить в это окно не требуется.

При загрузке списка появятся сообщения **«загрузка началась»** и
**«Список готов: … предметов»**. Когда вы просто смотрите таблицу, окно может
молчать — это нормально.

В старой версии строки **`GET … 200`** означали обычные успешные обращения
браузера к приложению. Они **не означали получение цен из игры**. В новой
версии этот служебный поток по умолчанию скрыт. Для проверки собственных
наблюдений смотрите число записей и время последнего пакета в **«Мои наблюдения»**.

Внутри приложения есть раздел **«Как пользоваться»** с теми же подсказками.

## Что означают столбцы

| Надпись | Простыми словами |
|---|---|
| Продают от | Самая низкая известная цена, по которой кто-то выставил предмет на продажу |
| Покупают до | Самая высокая известная цена заявки на покупку: предложение покупателя |
| 1H / 24H / 7D | Известный объём продаж за последние завершённые час / 24 часа / 7 суток |
| Давность цены | Сколько времени прошло с наблюдения цены |
| «Нет цены» / `—` | Данных нет; это **не нулевая цена** и не доказательство отсутствия продаж |
| `≥` перед объёмом | История неполная; показана только известная часть продаж |

Источник цен обновляется силами игроков, поэтому некоторые предметы и города
могут не иметь свежих данных. Доступная цена не гарантирует, что по ней удастся
купить или продать целую партию. Интерпретация временных границ истории ещё
ожидает живой проверки; пока не используйте объёмы как подтверждённую основу
крупной сделки.

**Caerleon и Black Market — два разных рынка.** Для Black Market показывается
цена заявки на покупку, а не обычная цена выставления товара.

## У меня уже есть старый Albion Data Client. Что с ним делать?

**Пока оставьте его как есть. Для первого запуска Trade Desk он не требуется.**

Это две отдельные программы:

* **Trade Desk** показывает и анализирует полученные данные.
* **Albion Data Client** собирает наблюдения, когда вы вручную смотрите рынок
  в игре, и отправляет их в общую базу Albion Data Project.

При обычном запуске Data Client отправляет наблюдения в общую базу. Для режима
**без публикации своих наблюдений** используйте отдельный Private Market Scanner
ниже. Обычный ярлык клиента для этого не подходит. Наша программа при этом
может отдельно читать публичные цены и обновления сообщества.

### Если хотите обновить официальный клиент

1. Закройте старый Data Client, в том числе его значок возле часов Windows,
   если он там есть. Две копии одновременно запускать не нужно.
2. Откройте **[официальную страницу последнего выпуска](https://github.com/ao-data/albiondata-client/releases/tag/0.1.61)**.
3. Внизу страницы раскройте **Assets** — это список файлов для скачивания.
4. Скачайте **`albiondata-client-amd64-installer.exe`** и запустите установку.
   Файлы `Source code`, `.gz` и вариант `mac.zip` для этого не нужны.
5. После установки запустите клиент. Если прежняя версия уже работает
   и собирает данные, переустанавливать всё ради первого запуска Trade Desk
   не требуется.

Название Windows-установщика проверено на официальной странице выпуска.
Для интеграции закреплён выпуск 0.1.61; другие версии не запускаются без повторного аудита и обновления контрольной суммы.

**Про Npcap:** это отдельный компонент, который может понадобиться Data Client
для получения рыночных данных из игры. Если клиент сообщает, что его нет,
используйте **[официальную загрузку Npcap](https://npcap.com/#download)**.
При установке выберите **«Install Npcap in WinPcap API-compatible Mode»**,
если этот пункт предлагается. Если старый клиент уже успешно собирает данные,
начинать с переустановки драйвера не нужно.

Подключение AOD выполняется кнопкой «Запустить сборщик», без скачивания PowerShell-файла и ручной настройки SQLite. Отдельный файл запуска оставлен только в «Диагностике»; обычному пользователю он не нужен. Приватность полного Windows-клиента не объявлена подтверждённой: [границы проверки](docs/PRIVATE_SCANNER.md).


## Как пользоваться потом

* **Открыть приложение:** дважды нажать `start.cmd` в той же папке.
* **Обновить цены:** выбрать сервер, город и качество, отметить предметы
  и нажать «Загрузить цены выбранных». Список предметов каждый раз скачивать не надо.
* **Посмотреть другие города:** нажать на название предмета в таблице.
  В карточке будут только те рыночные данные, которые уже получены.
* **Собрать ресурсы для крафта:** открыть **«Крафт и наборы»** или нажать
  **«В набор для крафта»** в строке предмета, у которого есть рецепт.
* **Сохранить в Excel:** нажать **«Сохранить в Excel»** над таблицей. Скачается новый
  файл; существующие Excel-книги программа не меняет.
* **Закрыть приложение:** в тёмном окне с текстом нажать **Ctrl+C**.
  Если закрыть только вкладку браузера, сама программа продолжит работать.

Данные, избранное и сохранённые наборы хранятся в **%LOCALAPPDATA%\AlbionTradeDesk\trade-desk.sqlite3**. Путь виден в панели сборщика. Эта папка не зависит от папки программы и сохраняется при обновлении. На первом запуске старая база из папки data рядом с start.cmd автоматически копируется в пользовательскую папку, если новой базы там ещё нет; оригинал не удаляется. Явный --data-dir для разработчиков остаётся доступен.

### Как обновить уже установленную программу

1. Остановите сборщик и Trade Desk (в разделе «Данные и настройки» есть «Закрыть Trade Desk»).
2. Распакуйте новую программу в новую папку и запустите её. Пользовательская база остаётся на месте; переносить её при следующих обновлениях не нужно.
3. Для самого первого переноса старой базы оставьте старую папку data рядом с обновлённым start.cmd либо восстановите резервную копию в пользовательский каталог перед запуском. Новая база автоматически не перезаписывается.

Windows exe собран workflow Windows application в GitHub Actions. Windows-тесты и проверка упакованного exe выполнены; результаты приведены в docs/WINDOWS_BUILD_RESULT.md. Для исходного ZIP необходим Python 3.12+; запуск — двойным щелчком start.cmd. Для разработчика: python -m pip install pyinstaller==6.16.0 и python -m PyInstaller --noconfirm AlbionTradeDesk.spec на Windows x64.

## Если что-то не получается

| Что случилось | Что сделать |
|---|---|
| `start.cmd` не запускает приложение или пишет, что Python не найден | Завершите установку Python из шага 2. Если установлен старый Python, нужна версия 3.12 или новее. Запустите `start.cmd` ещё раз |
| Браузер не открылся | Пока тёмное окно работает, вручную откройте адрес из шага 3 |
| Адрес в браузере не открывается | Проверьте, что тёмное окно не закрылось и в нём нет ошибки. Сам адрес без запущенного `start.cmd` не работает |
| Таблица совсем пустая | Нажмите большую кнопку «Загрузить список предметов» на главной странице. Если он уже загружен, очистите поиск и отключите «Избранное» / «Только с ценами» |
| Предметы видны, но вместо цен прочерки | Нажмите «Узнать цену» в строке предмета. Проверьте выбранные город, сервер и качество. У источника также может не быть нужных наблюдений |
| Обновление показывает ошибку | Скопируйте сообщение из приложения или пришлите скриншот. Переустановка Data Client не исправляет все ошибки загрузки цен |
| В браузере написано `AnkiConnect v.6` | Это страница Anki, а не Trade Desk. Скачайте свежую версию Trade Desk, запустите `start.cmd` и откройте **адрес из его тёмного окна**. Anki закрывать не нужно |
| При запуске написано, что порт недоступен | Обновлённая программа сама попробует другой порт; используйте адрес, который она напечатает |

Если застряли, достаточно прислать **скриншот последнего окна и номер шага**.
По ним можно будет понять, что именно мешает запуску.

### Все рамки, график и ваша таблица ткани

**Рамки — это качество предмета.** В поле «Качество» появились «Любая рамка»
и «Все рамки». Приложение запрашивает I–V сразу и показывает цену каждой отдельно.
Для общей подсказки выбирает свежую цену среди обычного, хорошего, выдающегося
и отличного качества. Если свежая цена найдена только у шедевра, это явно
подписано. Цена шедевра не заменяет обычные рамки незаметно.
Выбор конкретного качества по-прежнему означает только это качество.

По умолчанию предметы показаны **карточками**. «Таблица» возвращает табличный
вид для сравнения и экспорта. В наборе для крафта материалы также расположены
карточками; шрифт и числа стали плотнее и контрастнее.

Нажмите **«График и города»** на карточке предмета. Наверху — пять рамок,
ниже — цена и продажи за **6/12 часов, сутки, неделю, четыре недели** или свои
даты. Город и качество истории выбираются отдельно. **«Загрузить цены города · I–V»**
читает все рамки выбранного города; **«Загрузить общую историю за этот период»**
запрашивает историю выбранного качества. Эти кнопки читают общие данные, а
собственные наблюдения остаются отдельным источником.

Линия на графике — историческая средняя цена; столбики — количество продаж.
Наведите на точку для подробностей. Пропуски не считаются нулём, «≥» означает
только известную часть продаж. На графике не смешиваются качества.

Слева добавлена **«Ткань · мой Excel»** — расчёт из вашей книги. Основной вариант
повторяет вашу логику: **возврат 53,9%, первая партия 100 и ещё пять повторов**.
Дробная оценка даёт **211,6007192** продукции, то есть **111,6007192** сверх первых
100. Для примера T8.2 из книги Focus составляет **35 079,1672**. Четыре повтора
дают ещё **107,051427**. Коэффициент 111 был округлённым результатом этого метода.

* **Возврат, %** — введите итоговое значение из окна станка с нужным Focus,
  городом и бонусами дня. Приложение не складывает эти бонусы самостоятельно.
* **Повторных переработок** — сколько раз использовать вернувшиеся ресурсы
  после первой партии. По умолчанию пять; ноль означает только первую партию.
* **Ресурсы** — «Как в Excel» сохраняет дробную модель. «Целые материалы · вниз»
  округляет каждый возвращённый ингредиент вниз и проверяет, хватает ли обоих
  материалов на следующую операцию. Это отдельный осторожный сценарий,
  а не утверждение о точном игровом округлении.
* Персиковые поля цен можно менять. Цена покупки ткани этого тира используется
  как цена входной ткани следующего тира того же зачарования.
* Налоги и станция задаются отдельно, по умолчанию ноль. Из исходной таблицы
  неизвестно, включены ли они в цену продажи — не учитывайте их дважды.
* **«Сохранить настройки и цены»** сохраняет их на вашем компьютере.
  **«Сохранить и скачать Excel»** создаёт новую книгу с вашими настройками,
  формулами, пояснениями и исходным листом для сравнения.

Числа цен из присланного Excel — ручные исходные значения с неизвестной датой,
не текущие котировки AODP. Focus сохраняет приближение исходной формулы;
фактическое игровое округление ещё требует проверки. Подробнее о проверке книги:
[разбор расчёта](docs/CLOTH_AUDIT.md).
