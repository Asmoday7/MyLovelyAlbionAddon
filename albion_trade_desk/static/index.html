ПРОИСХОЖДЕНИЕ ДАННЫХ

Источники и сканер.

Наблюдения сообщества и локальный поток — с явными ограничениями.

Albion Data Project

REST-обновление для выбранных предметов, города и качества. Цены кэшируются 15 минут, история — 1 час.

Наличие подключения определяется реальным запросом, а не наличием настроенного адреса.

Локальный приёмник Эксперимент

HTTP-приёмник работает вместе с приложением. Совместимость формата проверяется тестами; проверка с игрой на Windows ещё не выполнена.

Сообщений от Data Client пока нет.

Команда сохраняет стандартную отправку AODP. Регион в локальном URL должен совпадать с сервером игры. Личные данные не запрашиваются.

Последние обновления

Что пока не подключено

NATS, импорт массовых SQL-дампов, полная глубина заявок. Частичные локальные наблюдения не считаются полной копией рынка. Отсутствие заявки не доказывает её продажу.

ВАШЕ РАБОЧЕЕ МЕСТО

Данные и настройки.

Локальная база SQLite. Настройки сохраняются между запусками.

Каталог Albion

Все доступные предметы, RU/EN, категории и рецепты из ao-data/ao-bin-dumps. Обновляйте после игровых патчей.

Свежесть наблюдений

Устаревшие цены остаются видимыми с отметкой. Обновление HTTP-кэша не делает старое рыночное наблюдение свежим.

Импорт рыночного JSON

Для сохранённых ответов AODP. Сервер берётся из переключателя сверху и не определяется автоматически.

Никаких демонстрационных цен в рабочую базу не добавляется.

Excel и резервное копирование

CSV в UTF-8 и XLSX с отдельным листом MarketPrices. Время — Unix UTC seconds, coverage — число от 0 до 1.

Power Query: JSON API /api/export.json с параметрами server, city, quality. Подробности — в README.
