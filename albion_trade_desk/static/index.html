Эксперимент · выключен по умолчанию
Разрешение Sandbox Interactive на приватный режим не подтверждено. Полная сетевая проверка с реальной игрой на Windows не выполнена. Наличие пакетов в базе само по себе не доказывает отсутствие внешних отправок.
Не запускайте обычный Data Client одновременно. При шифровании данных обход не выполняется.

Запуск клиента на Windows
1. Включите приёмник здесь.
2. Скачайте файл запуска ниже.
3. Нажмите на него правой кнопкой → «Запуск с помощью PowerShell».
4. Разрешите запрос Windows и выберите установленный официальный albiondata-client.exe.
Файл блокирует внешние соединения выбранного клиента через брандмауэр Windows и проверяет другие копии и автозапуск. Запускайте его на том же Windows-компьютере, где работает Trade Desk. Код игры не меняется.
Не меняет политику выполнения скриптов. Если Windows запрещает запуск, остановитесь и пришлите текст ошибки. Проверка защиты Windows пока не выполнена.

    
Что именно сохраняется
Рыночные заявки и история с сервером, городом, качеством, источником и временем. Персональные темы не принимаются. Все масштабы истории сохраняются в исходном виде; только подтверждённые почасовые интервалы участвуют в 1H/24H/7D. История без сопоставленного названия сохраняется до обновления каталога.
Облачная синхронизация отсутствует. Данные не пересылаются из приёмника в AODP. Публичные REST и NATS можно читать отдельно. После перезапуска Trade Desk приватный приёмник снова выключен.

  

  

    
ДАВАЙТЕ ПО ПОРЯДКУ
Как пользоваться.
Для первых цен хватит самого Trade Desk и подключения к Интернету.

    
1
Загрузите список предметов
На странице «Цены предметов» нажмите «Загрузить список предметов». Дождитесь сообщения о готовности. Это названия и рецепты — сами цены загружаются отдельно.
2
Найдите предмет из игры
Введите название в поиск: например, «Сумка» или «Rift Crystal». Для вашего кристалла нажмите пример ниже. Выберите тот же город и качество, что в игре.
3
Нажмите «Узнать цену»
Кнопка находится в каждой строке таблицы. Для одного предмета галочка не нужна. Для нескольких отметьте галочки в первом столбце и нажмите «Загрузить цены выбранных» под таблицей.
Если источник не знает цену для этого города и качества, останется «Нет цены» — это не ошибка и не нулевая стоимость.

    
Что должно быть в тёмном окне Windows?
Это служебное окно, оно поддерживает работу приложения. Его можно свернуть. Все действия выполняйте в браузере.
При обычной работе окно может молчать — это нормально. Строки GET … 200 в старой версии означали, что браузер успешно открыл страницу или проверил состояние приложения. Они не подтверждают получение рыночных данных.
Для завершения работы нажмите Ctrl+C в этом окне.
Albion Trade Desk запущен.
Адрес приложения: адрес вашего запуска
Окно можно свернуть. Работайте в браузере.
Для остановки нажмите Ctrl+C.

    
А если я хочу видеть свои цены из игры?
Открытый рынок в Albion сам по себе не передаёт цены в Trade Desk. Нужны отдельно запущенный официальный Data Client и его локальное подключение. Приватный режим настраивается в «Мои наблюдения»; он экспериментальный и не включается автоматически.
Проверяйте время последнего пакета и число принятых записей в панели. Если там ничего нет, данные из игры пока не поступают. Для первого знакомства начните с общих цен.

ВАШЕ РАБОЧЕЕ МЕСТО
Данные и настройки.
Локальная база SQLite. Настройки сохраняются между запусками.

    
Список предметов Albion
Все доступные предметы, RU/EN, категории и рецепты из ao-data/ao-bin-dumps. Обновляйте после игровых патчей.
Свежесть наблюдений
Устаревшие цены остаются видимыми с отметкой. Обновление HTTP-кэша не делает старое рыночное наблюдение свежим.

    
Импорт файлов и подключение Excel — для опытных пользователей
Импорт рыночного JSON
Для сохранённых ответов AODP. Сервер берётся из переключателя сверху и не определяется автоматически.
Никаких демонстрационных цен в рабочую базу не добавляется.
Excel и резервное копирование
CSV в UTF-8 и XLSX с отдельным листом MarketPrices. Время — Unix UTC seconds, coverage — число от 0 до 1.
Power Query: JSON API /api/export.json с параметрами server, city, quality. Подробности — в README.
